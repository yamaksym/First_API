# First_API
# 1. What you need to run this project?
1. Python 3.13 (main language)
2. Flask
3. Any browser (e.g. Chrome)
4. Python interpreter (but not PyCharm Community Edition, it's not working there...)

# 2. Structure of the project:
# 2.1 Application
To run this project go to this folder and run the only file it has (api_ver_2.py). Also, it is the brain of the project.

# 2.2 Website
This folder contains and controls everything that user sees.
There are three folders:
1. CSS
    Contains style.css, which has a style for the page.
2. HTML
    Contains index.html, that maps and shows everything on the screen.
3. JS
    Contains script.js, the 'brain' of the webpage.
